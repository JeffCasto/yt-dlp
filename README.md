# Chrome Extension Starter Template

This is a starter template for building a Chrome extension.

## File Structure

- `manifest.json`: The main configuration file for the extension.
- `popup.html`: The HTML file for the extension's popup UI.
- `popup.js`: The JavaScript file for the popup logic.
- `styles.css`: The CSS file for styling the popup.
- `background.js`: The service worker for background tasks.
- `content.js`: The script that runs in the context of web pages.
- `images/`: A directory to store icons for the extension.

## Getting Started

1. Clone this repository.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable "Developer mode".
4. Click "Load unpacked" and select the directory of this repository.
